AutoGift — автоматизация аренды Telegram Gift

Python · Telegram Bot API · Fanpay · Starvel

Полностью автоматизированная система аренды подарков в Telegram. Приём оплаты через Fanpay и Starvel, аренда подарка через зеркального бота по минимальной цене, выдача клиенту с инструкцией.

  • Покупатель оплачивает → получает инструкцию → переходит в бота
  • Бот запрашивает Ton Connect / ссылку → авто-аренда в зеркальном боте
  • Выдача готового подарка + инструкция покупателю
  • Отдельный бот уведомляет админа о всех заказах
  • Единый скрипт работает на Fanpay и Starvel через одну схему
